# 랩 01 · 이름 입력받아 인사하기

[← 랩 목록](../README.md) · [관련 단원](../../02-variables-and-input/README.md)

**배울 것:** input으로 받은 글자가 변수에 담기는 것을 확인합니다.

## 먼저 실행하기

[starter.py](starter.py)를 열어 ▶ **Run Python File in Terminal**로 실행합니다. 입력을 묻는 경우 Terminal을 클릭해 입력하고 Enter를 누릅니다. 이 랩의 조건은 **이름에 민지 입력**입니다. 아래 출력에는 입력 안내 문구를 제외했습니다.

시작 코드는 실행되지만 아직 목표를 완성하지 않은 상태입니다.

```text
안녕하세요, 친구
```

## 직접 바꿀 것

고정된 친구 대신 입력한 이름을 출력합니다. 파일 아래에 새 대입문을 덧붙이기보다 기존 줄을 고칩니다. TODO 주석이 있으면 그 줄을 먼저 보고, 준비 랩에서는 이미 완성된 예제의 문구나 숫자 한 곳을 바꿉니다.

현재 코드는 다음과 같습니다.

```python
# input은 Terminal에서 이름을 입력받습니다. 입력 후 Enter를 누릅니다.
name = input("이름> ")
# TODO: 아래 문구 대신 입력한 name을 출력하도록 바꿉니다.
print("안녕하세요,", "친구")
```

<details>
<summary>첫 수정 힌트 · 필요하면 펼치기</summary>

마지막 print의 두 번째 값 `"친구"`를 따옴표 없는 name으로 바꿉니다.

</details>
