# 랩 02 · 가격과 개수로 총액 구하기

**배울 것:** 변수에 저장한 숫자로 곱셈합니다.

## 먼저 실행하기

[starter.py](starter.py)를 열어 ▶ **Run Python File in Terminal**로 실행합니다. 입력을 묻는 경우 Terminal을 클릭해 입력하고 Enter를 누릅니다. 이 랩의 조건은 **입력 없음 · price=1200, count=3**입니다. 아래 출력에는 입력 안내 문구를 제외했습니다.

시작 코드는 실행되지만 아직 목표를 완성하지 않은 상태입니다.

```text
총액: 0 원
```

## 직접 바꿀 것

1200원짜리 물건 3개의 총액 3600원을 출력합니다. 파일 아래에 새 대입문을 덧붙이기보다 기존 줄을 고칩니다. TODO 주석이 있으면 그 줄을 먼저 보고, 준비 랩에서는 이미 완성된 예제의 문구나 숫자 한 곳을 바꿉니다.

현재 코드는 다음과 같습니다.

```python
# 숫자를 넣은 변수 두 개입니다. 가격은 정수 1200원, 개수는 3개입니다.
price = 1200
count = 3
# TODO: 0 대신 가격과 개수를 곱한 식을 넣습니다.
total = 0
print("총액:", total, "원")
```

<details>
<summary>첫 수정 힌트 · 필요하면 펼치기</summary>

total = 0에서 0을 price * count로 바꿉니다.

같은 입력으로 다시 실행했을 때 아래 결과가 나오는지 확인합니다.

총액이 3600원이 된 뒤 count만 5로 바꾸면 6000원입니다. 곱셈과 변수의 관계를 한 번 더 확인합니다.
