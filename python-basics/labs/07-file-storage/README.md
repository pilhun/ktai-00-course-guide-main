# 선택 랩 07 · 한 문장 저장하고 읽기

[← 랩 목록](../README.md) · [관련 단원](../../07-json-and-files/README.md)

**배울 것:** 파일에 쓴 글자를 다시 읽어 확인합니다.

## 먼저 실행하기

[starter.py](starter.py)를 열어 ▶ **Run Python File in Terminal**로 실행합니다. 입력을 묻는 경우 Terminal을 클릭해 입력하고 Enter를 누릅니다. 이 랩의 조건은 **입력 없음**입니다. 아래 출력에는 입력 안내 문구를 제외했습니다.

준비된 예제를 먼저 실행한 뒤, 아래에서 안내한 값 한 곳을 바꾸어 결과를 비교합니다.

```text
파일 내용: 안녕하세요.
```

## 직접 바꿀 것

저장할 문장을 오늘 배운 내용으로 바꿉니다. 파일 아래에 새 대입문을 덧붙이기보다 기존 줄을 고칩니다. TODO 주석이 있으면 그 줄을 먼저 보고, 준비 랩에서는 이미 완성된 예제의 문구나 숫자 한 곳을 바꿉니다.

현재 코드는 다음과 같습니다.

```python
# 선택 파일 실습입니다. Path는 Python 기본 제공 파일 위치 기능입니다.
from pathlib import Path
message = "안녕하세요."  # TODO: 오늘 배운 내용을 한 문장으로 바꿉니다.
# 이 코드 파일 옆에 저장합니다. 다음 실행에서는 같은 파일의 내용을 덮어씁니다.
path = Path(__file__).with_name("practice-note.txt")
path.write_text(message, encoding="utf-8")
loaded = path.read_text(encoding="utf-8")  # 저장한 글자를 다시 읽습니다.
print("파일 내용:", loaded)
```

message에 넣는 따옴표 안 문장만 바꿉니다. 준비된 파일 위치·저장·읽기 코드는 유지합니다.

## 수정 후 확인하기

같은 입력으로 다시 실행했을 때 아래 결과가 나오는지 확인합니다.

```text
파일 내용: 숫자의 합을 구하는 방법을 배웠습니다.
```

같은 폴더의 practice-note.txt를 VS Code에서 열어 글자도 비교합니다. 다시 실행하면 이 파일의 내용을 덮어씁니다. 파일은 연습 결과이며 Git 업로드에서 제외합니다. JSON으로 저장하는 과제는 아닙니다.
