# 준비 05A · 위치와 이름표 구분하기

[← 랩 목록](../README.md) · [관련 단원](../../05-dictionaries/README.md)

**배울 것:** 리스트의 위치와 딕셔너리의 키를 구분합니다.

## 먼저 실행하기

[trace_collections.py](trace_collections.py)를 열어 ▶ **Run Python File in Terminal**로 실행합니다. 입력을 묻는 경우 Terminal을 클릭해 입력하고 Enter를 누릅니다. 이 랩의 조건은 **입력 없음**입니다. 아래 출력에는 입력 안내 문구를 제외했습니다.

준비된 예제를 먼저 실행한 뒤, 아래에서 안내한 위치 한 곳을 바꾸어 결과를 비교합니다.

```text
목록의 값: 10
이름: 민지
```

## 직접 바꿀 것

이름은 유지하고 목록에서 두 번째 수 20을 꺼냅니다. 파일 아래에 새 대입문을 덧붙이기보다 기존 줄을 고칩니다. TODO 주석이 있으면 그 줄을 먼저 보고, 준비 랩에서는 이미 완성된 예제의 문구나 숫자 한 곳을 바꿉니다.

현재 코드는 다음과 같습니다.

```python
# 리스트는 위치로, 딕셔너리는 키로 값을 찾습니다.
numbers = [10, 20, 30]
student = {"name": "민지", "age": 20}
print("목록의 값:", numbers[0])  # 0은 첫 번째 위치입니다.
print("이름:", student["name"])
```

<details>
<summary>첫 수정 힌트 · 필요하면 펼치기</summary>

numbers[0]을 numbers[1]로 바꿉니다. 딕셔너리는 건드리지 않습니다.

</details>
