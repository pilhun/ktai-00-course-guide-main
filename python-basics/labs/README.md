# Python 기초 랩 · 익숙한 작은 문제부터

[← Python 기초](../README.md)

기본은 **시작 코드 실행 → 한 곳 수정 → 예상 결과 비교 → 풀이 확인**입니다. 먼저 관련 단원을 읽고 예제를 실행합니다. TODO는 바꿀 곳을 알려 주는 주석입니다. 시작 코드는 실행되지만 목표 출력과 다를 수 있습니다.

.py 파일을 열어 ▶ **Run Python File in Terminal**로 실행합니다. 입력을 묻는 프로그램은 아래 Terminal에 입력하고 Enter를 누릅니다. 00은 기본 Python으로 실행하며 API 키·가상환경·추가 패키지를 준비하지 않습니다.

## 풀이를 비교하는 방법

각 랩의 접힌 풀이에서 같은 폴더 solution.py를 엽니다. 직접 시도한 뒤 같은 입력으로 비교합니다. 바꾼 줄과 결과를 자기 말로 설명해 봅니다. 추가 응용으로 숫자를 바꿨다면 풀이의 기본 숫자와 결과가 달라도 정상일 수 있습니다.

오류가 나면 마지막으로 성공한 값부터 다시 실행하고 최근 수정한 한 줄을 확인합니다. 선생님에게 질문할 때는 단원·파일·입력·오류 마지막 3~5줄을 함께 알려 주세요.

파일·JSON·종합 앱은 [나중에 다시 풀 자료](../../CHALLENGES.md)로 남겨도 됩니다. 수업 안에서 선생님과 범위를 정해 복습하며 다음 교과 시작 조건으로 삼지 않습니다.
