# 선택 오류 읽기 · 숫자·변수·키 확인

[← 랩 목록](../README.md) · [변수와 입력](../../02-variables-and-input/README.md) · [딕셔너리](../../05-dictionaries/README.md)

변수·조건문·딕셔너리를 배운 뒤 필요한 사례를 골라 보는 선택 자료입니다. **일부러 오류가 나도록 만든 파일**이며 기본 실습을 시작하기 위한 필수 시험이 아닙니다.

[error_cases.py](error_cases.py)를 ▶로 실행합니다. Terminal의 실행할 사례에 0을 넣으면 민지가 출력됩니다. 다음은 한 번에 한 가지 오류만 확인합니다.

| 사례 | 입력·동작 | 예상 결과와 고칠 곳 |
|---|---|---|
| 0 | 0 선택 | 정상 출력 민지 |
| 1 | 1 선택 후 숫자 대신 세 입력 | ValueError. int는 숫자 형태 글자를 정수로 바꿈 |
| 2 | 2 선택 | NameError. 만든 이름 score와 사용한 scores의 철자를 대조 |
| 3 | 3 선택 | KeyError. 딕셔너리에 없는 text 대신 실제 키 name 사용 |

Traceback의 마지막 오류 이름과 파일의 줄 번호를 먼저 봅니다. 어려운 오류 전문을 외우거나 Python을 재설치하지 않습니다.
