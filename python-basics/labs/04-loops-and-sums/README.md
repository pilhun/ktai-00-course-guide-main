# 랩 04 · 1부터 5까지 합 구하기

[← 랩 목록](../README.md) · [관련 단원](../../04-lists-and-loops/README.md)

**배울 것:** 반복할 때 이전 합계를 유지하며 수를 하나씩 더합니다.

## 먼저 실행하기

[starter.py](starter.py)를 열어 ▶ **Run Python File in Terminal**로 실행합니다. 입력을 묻는 경우 Terminal을 클릭해 입력하고 Enter를 누릅니다. 이 랩의 조건은 **입력 없음**입니다. 아래 출력에는 입력 안내 문구를 제외했습니다.

시작 코드는 실행되지만 아직 목표를 완성하지 않은 상태입니다.

```text
합계: 5
```

## 직접 바꿀 것

1 + 2 + 3 + 4 + 5의 합계 15를 구합니다. 파일 아래에 새 대입문을 덧붙이기보다 기존 줄을 고칩니다. TODO 주석이 있으면 그 줄을 먼저 보고, 준비 랩에서는 이미 완성된 예제의 문구나 숫자 한 곳을 바꿉니다.

현재 코드는 다음과 같습니다.

```python
total = 0  # 반복을 시작하기 전에 합계를 0으로 준비합니다.
for number in range(1, 6):  # 1, 2, 3, 4, 5를 하나씩 사용합니다.
    # TODO: 이번 수만 저장하지 않고 이전 합계에 이번 수를 더합니다.
    total = number
print("합계:", total)
```

<details>
<summary>첫 수정 힌트 · 필요하면 펼치기</summary>

반복 안의 total = number를 total = total + number로 바꿉니다.

</details>

## 수정 후 확인하기

같은 입력으로 다시 실행했을 때 아래 결과가 나오는지 확인합니다.

```text
합계: 15
```

합계가 15가 된 뒤 선택으로 range(1, 6)을 range(1, 11)로 바꿔 봅니다. 1부터 10까지의 합계는 55입니다. 먼저 더하는 식을 고치고 나중에 범위를 바꿉니다.
