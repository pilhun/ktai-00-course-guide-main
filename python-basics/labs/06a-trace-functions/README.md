# 준비 06A · 함수의 반환값 따라가기

[← 랩 목록](../README.md) · [관련 단원](../../06-functions/README.md)

**배울 것:** 반환값을 변수에 저장하고 다른 계산에 사용합니다.

## 먼저 실행하기

[trace_function.py](trace_function.py)를 열어 ▶ **Run Python File in Terminal**로 실행합니다. 입력을 묻는 경우 Terminal을 클릭해 입력하고 Enter를 누릅니다. 이 랩의 조건은 **입력 없음**입니다. 아래 출력에는 입력 안내 문구를 제외했습니다.

준비된 예제를 먼저 실행한 뒤, 아래에서 안내한 값 한 곳을 바꾸어 결과를 비교합니다.

```text
함수 결과: 8
하나 더한 값: 9
```

## 직접 바꿀 것

함수에 전달하는 4를 5로 바꾸고 두 출력이 함께 달라지는지 봅니다. 파일 아래에 새 대입문을 덧붙이기보다 기존 줄을 고칩니다. TODO 주석이 있으면 그 줄을 먼저 보고, 준비 랩에서는 이미 완성된 예제의 문구나 숫자 한 곳을 바꿉니다.

현재 코드는 다음과 같습니다.

```python
def double_number(number):  # 전달받은 수를 두 배로 만드는 함수입니다.
    return number * 2

result = double_number(4)  # 8을 돌려받아 result에 저장합니다.
print("함수 결과:", result)
print("하나 더한 값:", result + 1)  # return 값은 다른 계산에도 쓸 수 있습니다.
```
