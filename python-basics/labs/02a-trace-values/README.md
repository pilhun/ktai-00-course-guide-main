# 준비 02A · 변수의 값 따라가기

[← 랩 목록](../README.md) · [관련 단원](../../02-variables-and-input/README.md)

**배울 것:** 이전 값에 숫자를 더해 다시 저장하는 순서를 읽습니다.

## 먼저 실행하기

[trace_values.py](trace_values.py)를 열어 ▶ **Run Python File in Terminal**로 실행합니다. 입력을 묻는 경우 Terminal을 클릭해 입력하고 Enter를 누릅니다. 이 랩의 조건은 **입력 없음**입니다. 아래 출력에는 입력 안내 문구를 제외했습니다.

준비된 예제를 먼저 실행한 뒤, 아래에서 안내한 값 한 곳을 바꾸어 결과를 비교합니다.

```text
처음: 3
더한 뒤: 5
```

## 직접 바꿀 것

더하는 수를 2에서 4로 바꾸고 결과를 비교합니다. 파일 아래에 새 대입문을 덧붙이기보다 기존 줄을 고칩니다. TODO 주석이 있으면 그 줄을 먼저 보고, 준비 랩에서는 이미 완성된 예제의 문구나 숫자 한 곳을 바꿉니다.

현재 코드는 다음과 같습니다.

```python
# 한 줄씩 실행될 때 값이 어떻게 변하는지 먼저 예상합니다.
number = 3
print("처음:", number)
number = number + 2  # 기존 값 3에 2를 더해 5를 저장합니다.
print("더한 뒤:", number)
```

<details>
<summary>첫 수정 힌트 · 필요하면 펼치기</summary>

number = number + 2의 마지막 수만 4로 바꿉니다.

</details>
