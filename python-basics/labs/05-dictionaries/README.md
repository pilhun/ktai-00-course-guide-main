# 랩 05 · 이름과 나이를 키로 읽기

[← 랩 목록](../README.md) · [관련 단원](../../05-dictionaries/README.md)

**배울 것:** 키에 따라 다른 값을 꺼냅니다.

## 먼저 실행하기

[starter.py](starter.py)를 열어 ▶ **Run Python File in Terminal**로 실행합니다. 입력을 묻는 경우 Terminal을 클릭해 입력하고 Enter를 누릅니다. 이 랩의 조건은 **입력 없음**입니다. 아래 출력에는 입력 안내 문구를 제외했습니다.

시작 코드는 실행되지만 아직 목표를 완성하지 않은 상태입니다.

```text
이름: 민지
나이: 민지
```

## 직접 바꿀 것

나이 줄에 이름 대신 숫자 20을 출력합니다. 파일 아래에 새 대입문을 덧붙이기보다 기존 줄을 고칩니다. TODO 주석이 있으면 그 줄을 먼저 보고, 준비 랩에서는 이미 완성된 예제의 문구나 숫자 한 곳을 바꿉니다.

현재 코드는 다음과 같습니다.

```python
# 딕셔너리에 이름과 나이를 저장합니다.
student = {"name": "민지", "age": 20}
print("이름:", student["name"])
# TODO: name 대신 나이를 가리키는 키를 사용합니다.
print("나이:", student["name"])
```

마지막 줄의 student["name"]만 student["age"]로 바꿉니다.
