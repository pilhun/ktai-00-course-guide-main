# 랩 03 · 양수·0·음수 구분하기

[← 랩 목록](../README.md) · [관련 단원](../../03-conditions/README.md)

**배울 것:** 비교 조건에 따라 다른 줄을 실행합니다.

## 먼저 실행하기

[starter.py](starter.py)를 열어 ▶ **Run Python File in Terminal**로 실행합니다. 입력을 묻는 경우 Terminal을 클릭해 입력하고 Enter를 누릅니다. 이 랩의 조건은 **정수에 3 입력**입니다. 아래 출력에는 입력 안내 문구를 제외했습니다.

시작 코드는 실행되지만 아직 목표를 완성하지 않은 상태입니다.

```text
음수입니다.
```

## 직접 바꿀 것

양수 입력에서 양수라는 문장이 나오도록 조건을 완성합니다. 파일 아래에 새 대입문을 덧붙이기보다 기존 줄을 고칩니다. TODO 주석이 있으면 그 줄을 먼저 보고, 준비 랩에서는 이미 완성된 예제의 문구나 숫자 한 곳을 바꿉니다.

현재 코드는 다음과 같습니다.

```python
number = int(input("정수> "))  # 3, 0, -2를 차례로 입력해 봅니다.
# TODO: False 대신 number가 0보다 큰지 비교하는 조건을 넣습니다.
if False:
    print("양수입니다.")
elif number == 0:  # ==는 두 값이 같은지 비교합니다.
    print("0입니다.")
else:
    print("음수입니다.")
```

<details>
<summary>첫 수정 힌트 · 필요하면 펼치기</summary>

if False:에서 False만 number > 0으로 바꿉니다. 들여쓰기와 elif·else는 유지합니다.

</details>

## 수정 후 확인하기

같은 입력으로 다시 실행했을 때 아래 결과가 나오는지 확인합니다.

```text
양수입니다.
```

0을 넣으면 `0입니다.`, -2를 넣으면 `음수입니다.`가 나오는지도 확인합니다. 한 번의 실행에 정수 하나씩 입력합니다.

## 스스로 확인할 것
