# 준비 00 · 첫 문장 바꾸기

[← 랩 목록](../README.md) · [관련 단원](../../01-run-and-print/README.md)

**배울 것:** print로 문장을 출력합니다.

## 먼저 실행하기

[first_run.py](first_run.py)를 열어 ▶ **Run Python File in Terminal**로 실행합니다. 입력을 묻는 경우 Terminal을 클릭해 입력하고 Enter를 누릅니다. 이 랩의 조건은 **입력 없음**입니다. 아래 출력에는 입력 안내 문구를 제외했습니다.

시작 코드는 실행되지만 아직 목표를 완성하지 않은 상태입니다.

```text
안녕하세요.
```

## 직접 바꿀 것

인사말을 `Python을 시작합니다.`로 바꿉니다. 파일 아래에 새 대입문을 덧붙이기보다 기존 줄을 고칩니다. TODO 주석이 있으면 그 줄을 먼저 보고, 준비 랩에서는 이미 완성된 예제의 문구나 숫자 한 곳을 바꿉니다.

현재 코드는 다음과 같습니다.

```python
# 첫 파일은 문장 한 줄을 출력합니다. 따옴표와 괄호를 유지하며 문구를 바꿉니다.
print("안녕하세요.")
```

<details>
<summary>첫 수정 힌트 · 필요하면 펼치기</summary>

따옴표 안의 글자만 바꾸고 괄호와 따옴표는 남깁니다.

</details>
