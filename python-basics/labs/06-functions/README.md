[← 랩 목록](../README.md) · [관련 단원](../../06-functions/README.md)

**배울 것:** 함수에 전달한 값과 돌려받는 값을 구분합니다.

## 먼저 실행하기

[starter.py](starter.py)를 열어 ▶ **Run Python File in Terminal**로 실행합니다. 입력을 묻는 경우 Terminal을 클릭해 입력하고 Enter를 누릅니다. 이 랩의 조건은 **입력 없음**입니다. 아래 출력에는 입력 안내 문구를 제외했습니다.

시작 코드는 실행되지만 아직 목표를 완성하지 않은 상태입니다.

```text
합계: 3
```

3과 5를 전달하면 합계 8을 반환하게 합니다. 파일 아래에 새 대입문을 덧붙이기보다 기존 줄을 고칩니다. TODO 주석이 있으면 그 줄을 먼저 보고, 준비 랩에서는 이미 완성된 예제의 문구나 숫자 한 곳을 바꿉니다.

현재 코드는 다음과 같습니다.

```python
# 함수 안에는 계산을, 함수 밖에는 출력을 둡니다.
def add_numbers(first, second):
    # TODO: 두 수의 합계를 돌려주도록 return 뒤의 식을 바꿉니다.
    return first
```

## 수정 후 확인하기

같은 입력으로 다시 실행했을 때 아래 결과가 나오는지 확인합니다.

```text

```

함수 호출의 숫자를 10과 20으로 바꾸면 합계 30입니다. 함수를 다시 정의하지 않고 다른 값을 전달해 사용합니다.
