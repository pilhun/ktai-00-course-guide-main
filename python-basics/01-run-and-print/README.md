# 01 · 파일 실행과 출력

**배울 것:** Python 파일을 열고 한 줄을 실행합니다. 문장과 숫자를 출력해 봅니다.

## print로 화면에 보여 주기

`print()`는 괄호 안의 값을 화면 아래 Terminal에 보여 줍니다. `print("안녕하세요.")`에서 따옴표 안은 글자, 괄호는 출력할 내용의 범위입니다. 영어 소문자 철자와 따옴표·괄호를 함께 확인합니다.

Python은 일반적으로 위에서 아래로 한 줄씩 실행합니다. 출력할 문장을 두 줄 적으면 화면에도 순서대로 두 줄이 나옵니다. `print(3 + 2)`는 글자 `3 + 2`를 보여 주는 것이 아니라 계산한 숫자 5를 보여 줍니다. `print("3 + 2")`와 비교할 수 있습니다.

코드 옆 `#` 뒤의 글자는 주석입니다. 사람이 읽는 설명이며 실행되지 않습니다. 문장을 바꾸려면 따옴표 안을 바꾸고, 새 결과를 보려면 저장 후 다시 실행합니다.

## 예제 파일과 예상 결과

각 파일을 따로 열어 ▶ **Run Python File in Terminal**로 실행합니다. 입력을 묻는 경우 아래 Terminal을 클릭해 값을 적고 Enter를 누릅니다. 여러 프로그램을 동시에 실행하지 않습니다.

### 인사말 두 줄과 덧셈 결과

[print_examples.py](print_examples.py)를 실행합니다. 아래는 문서의 기본값과 안내한 입력으로 실행한 예시입니다.

```text
안녕하세요.
저는 Python을 배우고 있습니다.
5
```

## 직접 한 곳 바꾸기

첫 문장만 `반갑습니다.`로 바꾸고 저장한 뒤 다시 실행합니다. 숫자 계산은 그대로 두고 첫 줄만 달라졌는지 확인합니다. 한 번에 따옴표와 문장 전체를 지우기보다 글자 부분만 바꿔 봅니다.

## 실행 화면 구분하기

- 가운데 편집기에는 `.py` 파일의 코드를 적습니다.
- ▶ **Run Python File in Terminal**로 파일 전체를 실행합니다.
- 아래 Terminal에는 출력이 보입니다. 출력 문장을 Python 코드에 다시 붙여 넣지 않습니다.

따옴표나 괄호를 빠뜨리면 오류가 날 수 있습니다. 마지막으로 바꾼 줄을 보고 처음 예제와 비교합니다. 오류를 해결하려고 Python을 다시 설치하지 않습니다.
