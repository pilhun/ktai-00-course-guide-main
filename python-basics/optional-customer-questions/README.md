# 선택 응용 · 숫자와 이름에서 고객 문의로

[← Python 기초](../README.md) · [선택 종합 앱](../labs/08-helpdesk-app/README.md)

기본 문법을 배우고 나서 읽는 연결 자료입니다. 이 폴더와 종합 앱을 모두 끝내야 01을 시작하는 것은 아닙니다.

| 이미 배운 것 | 고객 문의에 적용하면 |
|---|---|
| 이름 입력받기 | 문의 문장 입력받기 |
| 양수·음수 조건 | 문의가 비었는지 확인 |
| 숫자를 하나씩 읽기 | 문의 목록을 한 건씩 읽기 |
| 이름·나이 딕셔너리 | 문의 번호·본문 딕셔너리 |
| 두 수를 더하는 함수 | 반복 사용할 입력 정리 기능 |

[question_summary.py](question_summary.py)는 공백 정리·빈 값 확인·JSON 표시를 연결한 준비 예제입니다. 실행하면 Terminal에 문의 한 줄을 입력합니다. JSON·strip·raise 등 아직 낯선 부분은 선생님과 읽습니다. 이 예제는 LLM을 호출하지 않습니다.

[선택 종합 랩](../labs/08-helpdesk-app/README.md)은 메뉴·여러 함수·리스트 안의 딕셔너리·저장과 읽기를 함께 사용합니다. **기초 랩보다 어려운 참고 자료**이므로 처음부터 전체를 새로 작성하지 않습니다. 작은 부분을 살펴보고 필요할 때 돌아옵니다.
