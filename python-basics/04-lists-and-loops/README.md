# 04 · 리스트와 반복문으로 합계 구하기

[← Python 기초 목차](../README.md) · [랩 목록](../labs/README.md)

**배울 것:** 숫자 목록에서 값을 꺼내고 1부터 5까지의 합을 구합니다.

## 리스트는 여러 값을 순서대로 모은 것입니다

`numbers = [10, 20, 30]`은 수 세 개를 담은 리스트입니다. 대괄호 안의 위치 번호로 하나를 꺼냅니다. **첫 번째 위치는 0**이므로 numbers[0]은 10, numbers[1]은 20입니다. `len(numbers)`는 개수 3을 알려 줍니다.

for는 리스트의 값을 하나씩 꺼내 들여쓴 코드를 반복합니다. number는 이번에 꺼낸 값에 붙인 이름입니다. 반복문 자체를 복잡한 메뉴나 종료 명령과 함께 배우지 않습니다.

## range는 연속된 수를 만들 때 씁니다

`range(1, 6)`은 1, 2, 3, 4, 5를 차례로 사용합니다. 끝에 적은 6은 포함하지 않습니다. 숫자를 1부터 10까지 사용하고 싶으면 끝값을 11로 적습니다.

## 합계는 이전 값에 하나씩 더합니다

| 이번 수 | 이전 합계 | 더한 뒤 합계 |
|---:|---:|---:|
| 1 | 0 | 1 |
| 2 | 1 | 3 |
| 3 | 3 | 6 |
| 4 | 6 | 10 |
| 5 | 10 | 15 |

합계를 담을 total은 **반복문에 들어가기 전에** 0으로 준비합니다. 반복 안에서 매번 0으로 바꾸면 이전 계산을 잃습니다. `total = total + number`는 지금까지의 합계에 이번 수를 더합니다.

## 한 곳 바꾸어 응용하기

sum_numbers.py의 `range(1, 6)`만 `range(1, 11)`로 바꿉니다. 합계는 55입니다. 그 파일의 출력 설명도 ‘1부터 10까지’로 바꾸면 읽기 좋습니다.

## 숫자 목록의 합계와 평균

[list_total.py](list_total.py)는 [10, 20, 30]의 값을 하나씩 더합니다. range로 만든 수 대신 이미 저장한 리스트를 반복합니다. 합계를 개수 len(numbers)로 나누면 평균입니다.

```text
합계: 60
평균: 20.0
```

목록의 30만 60으로 바꾸면 합계 90, 평균 30.0입니다. 처음에는 목록을 비우거나 반복 입력 기능을 더하지 않고 숫자 한 곳만 바꿉니다. while·메뉴·무한 반복은 기본 랩에서 다루지 않습니다.
