# 02 · 변수·계산·입력

[← Python 기초 목차](../README.md) · [랩 목록](../labs/README.md)

**배울 것:** 숫자와 글자에 이름을 붙이고 두 수의 합을 구합니다.

## 변수는 값을 보관하는 이름입니다

`number = 3`은 오른쪽 숫자 3을 왼쪽 이름 number에 저장합니다. `=`는 수학에서의 같은 값 비교가 아니라 **값을 넣는 표시**입니다. `number = number + 2`는 현재 값 3에 2를 더해 5를 다시 저장한다는 뜻입니다.

| 표현 | 뜻 |
|---|---|
| `name = "민지"` | 문자열 저장 |
| `age = 20` | 정수 저장 |
| `height = 165.5` | 실수 저장 |
| `print(name)` | name에 저장된 값 출력 |
| `print("name")` | name이라는 글자 자체 출력 |

변수 이름은 뜻을 알 수 있게 적고 대소문자를 구분합니다. 처음에는 영어 소문자 이름으로 연습합니다.

## 숫자로 계산하기

| 기호 | 계산 | 예 |
|---|---|---|
| `+` | 더하기 | `3 + 5` → 8 |
| `-` | 빼기 | `5 - 3` → 2 |
| `*` | 곱하기 | `1200 * 3` → 3600 |
| `/` | 나누기 | `10 / 2` → 5.0 |

괄호 안 계산을 먼저 합니다. `(80 + 90) / 2`는 두 점수의 평균 85.0입니다. 지금은 숫자·식 하나를 바꾸며 결과를 읽고, 복잡한 수식이나 여러 자료구조를 함께 만들지 않습니다.

## input의 결과는 글자입니다

`input("이름> ")`은 Terminal에서 입력 후 Enter를 누를 때까지 기다립니다. 이때 프로그램이 멈추거나 고장 난 것이 아닙니다. 글자를 변수에 저장한 뒤 print로 확인합니다.

숫자를 입력해도 처음에는 문자열입니다. `"3" + "5"`는 글자를 이어 붙여 `"35"`가 됩니다. 숫자 합계 8을 구하려면 `int()`로 각각 정수로 바꿉니다. 처음에는 3, 5처럼 정수만 입력합니다. 한글·쉼표·소수점을 정수 입력란에 넣으면 변환 오류가 날 수 있습니다.

## 작은 단계로 연습하기

1. 이름 예제의 문구를 바꿉니다.
2. 숫자 예제에 3과 5를 넣어 합계 8을 확인합니다.
3. 10과 20으로 바꾸어 30이 되는지 봅니다.

숫자 합계가 된 뒤 가격×개수 계산으로 응용합니다. 첫 입력부터 오류 처리를 새로 만들 필요는 없습니다. `strip()` 같은 공백 정리는 뒤의 선택 고객 문의 예제에서 다시 설명합니다.
