# 05 · 이름표로 값 찾기

[← Python 기초 목차](../README.md) · [랩 목록](../labs/README.md)

**배울 것:** 이름과 나이를 딕셔너리에 담고 점수를 읽어 합계를 구합니다.

## 리스트의 위치와 딕셔너리의 키를 구분합니다

리스트는 몇 번째인지로 값을 찾습니다. 딕셔너리는 `name`처럼 붙인 이름표, 즉 **키**로 값을 찾습니다. 키와 값은 콜론으로 연결하고, 여러 쌍은 쉼표로 구분해 중괄호 안에 적습니다.

```python
student = {"name": "민지", "age": 20}
print(student["name"])
```

name이라는 키로 민지를 찾고 age라는 키로 20을 찾습니다. `student["age"] = 21`처럼 기존 키에 값을 넣으면 나이가 바뀝니다. 리스트 안에 여러 딕셔너리를 넣거나 자료를 검색하는 기능은 지금 함께 만들지 않습니다.

| 자료 | 꺼내는 방법 | 값 |
|---|---|---|
| `numbers = [10, 20]` | `numbers[0]` | 10 |
| `student = {"name": "민지"}` | `student["name"]` | 민지 |

## 점수도 이름표로 구분합니다

korean과 english 키에 점수 두 개를 저장한 뒤 값을 꺼내 더합니다. 계산은 앞에서 배운 덧셈·나눗셈 그대로입니다. 딕셔너리라는 새 개념을 배우는 것이며 점수 합계 계산법이 바뀌는 것은 아닙니다.

## 키 이름을 확인합니다

딕셔너리에 없는 키를 요청하면 KeyError가 납니다. 문자열 값이 틀렸다는 뜻과 키 이름이 없다는 뜻을 구분합니다. 먼저 name·age가 실제로 있는지 코드에서 확인합니다. 자세한 오류 연습은 [선택 오류 랩](../labs/03a-read-errors/README.md)에서 진행할 수 있습니다.
