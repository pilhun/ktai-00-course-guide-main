# 선택 07 · 글자를 파일로 저장하고 읽기

[← Python 기초 목차](../README.md) · [랩 목록](../labs/README.md)

**배울 것:** 화면 출력과 파일 저장의 차이를 보고, JSON은 선택 설명으로 읽습니다.

## print와 파일 저장은 다릅니다

print로 보인 문장은 Terminal의 출력입니다. 프로그램을 나중에 다시 실행할 때 읽으려면 파일에 저장할 수 있습니다. 먼저 짧은 문장 하나를 `.txt` 파일에 쓰고 다시 읽습니다. 숫자 목록·여러 학생·메뉴·JSON을 한 번에 묶지 않습니다.

## import는 준비된 기능을 가져옵니다

`from pathlib import Path`는 Python에 포함된 pathlib에서 Path 기능을 가져옵니다. 이 파일 예제는 추가 라이브러리를 설치하지 않습니다. `Path(__file__).with_name(...)`은 지금 코드 파일 옆의 자료를 가리키는 준비 코드입니다. 처음에는 그대로 두고 읽거나 저장할 문장부터 바꿉니다.

- `.py`는 코드를 실행하는 파일입니다.
- `.txt`는 글자를 저장한 자료입니다.
- `encoding="utf-8"`은 한글을 읽고 쓰는 문자 저장 방식입니다.

같은 이름에 쓰면 기존 내용을 바꿉니다. 예제의 practice-note.txt 외의 개인 파일을 지정하지 않습니다. 파일은 이 단원 폴더 안에 생성되며 Git 업로드 대상에서 제외합니다.

## 예제 파일과 예상 결과

각 파일을 따로 열어 ▶ **Run Python File in Terminal**로 실행합니다. 입력을 묻는 경우 아래 Terminal을 클릭해 값을 적고 Enter를 누릅니다. 여러 프로그램을 동시에 실행하지 않습니다.

### 제공된 greeting.txt 읽기

[read_text.py](read_text.py)를 실행합니다. 아래는 문서의 기본값과 안내한 입력으로 실행한 예시입니다.

```text
읽은 내용: 안녕하세요. 파일 읽기를 배웁니다.
```

### 문장을 저장하고 다시 읽기

[save_and_reload.py](save_and_reload.py)를 실행합니다. 아래는 문서의 기본값과 안내한 입력으로 실행한 예시입니다.

```text
다시 읽은 내용: 오늘도 Python을 연습합니다.
```

## JSON은 필요할 때 읽는 추가 설명입니다

JSON은 프로그램 사이에서 자료를 주고받을 때 사용하는 텍스트 형식입니다. Python 딕셔너리와 비슷해 보여도 파일 속 글자와 Python 자료는 구분합니다.

| 선택 예제 | 관찰할 것 |
|---|---|
| [dict_to_json.py](dict_to_json.py) | 이름·나이 딕셔너리를 JSON 글자로 표시 |
| [read_json.py](read_json.py) | [sample_student.json](sample_student.json)을 읽고 이름·나이 출력 |

json도 Python 기본 모듈입니다. 이 두 예제는 준비된 코드를 실행하며 관찰하는 자료입니다. 처음부터 JSON 저장·복원 기능을 혼자 구현하는 과제는 아닙니다. 파일·JSON을 모두 끝내야 01을 시작할 수 있는 것은 아닙니다.
