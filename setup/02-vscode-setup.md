# VS Code 설치

[← 설치와 첫 실행](README.md)

VS Code는 수업 파일을 열고 코드를 고치는 앱입니다.

## Windows

1. [다운로드 페이지](https://code.visualstudio.com/Download)에서 Windows 설치 파일을 받습니다.
2. 받은 설치 파일을 두 번 클릭합니다. 사용권 계약을 읽고 설치를 진행합니다.
3. 설치 위치는 기본값을 사용합니다. **Add to PATH** 항목이 보이면 선택합니다.
4. 설치가 끝나면 **Launch Visual Studio Code**를 선택하고 Finish를 누릅니다.

## macOS

1. 같은 다운로드 페이지에서 Mac에 맞는 파일을 받습니다. 기기 종류는 **Apple 메뉴 → 이 Mac에 관하여**에서 확인합니다.
2. ZIP을 받았다면 두 번 클릭해 압축을 풉니다.
3. Visual Studio Code 앱을 **응용 프로그램(Applications)** 폴더로 옮깁니다.
4. 응용 프로그램에서 앱을 엽니다. 처음 열기 확인이 나오면 다운로드한 앱 이름을 확인하고 엽니다.

## 처음 열린 화면 살펴보기

| 화면 위치 | 앞으로 할 일 |
|---|---|
| 왼쪽 Explorer 아이콘 | 수업 폴더와 파일을 엽니다. |
| 왼쪽 Extensions 아이콘 | Python 기능을 설치합니다. |
| 가운데 편집 영역 | Python 파일의 문구를 고칩니다. |
| 실행 후 아래쪽 Terminal | 프로그램이 출력한 결과를 봅니다. |

첫 화면의 테마나 AI 기능 안내는 나중에 설정할 수 있습니다. VS Code 창을 열 수 있으면 이 단계가 끝났습니다.

[Microsoft 공식 설치 안내](https://code.visualstudio.com/docs/setup/setup-overview)

## 수업에 필요한 기본 설정

수업에서는 **영어 메뉴**를 기준으로 진행합니다. 아래 영어 이름을 화면에서 찾고, 옆의 한국어 설명을 따라갑니다.

Settings는 왼쪽 아래 **톱니바퀴 → Settings**로 엽니다. Windows는 `Ctrl+,`, macOS는 `Command+,`로 열 수도 있습니다. 설정 화면에서 **User**를 선택하면 다음 교과 폴더에서도 같은 설정을 사용합니다.

### 1. 자동 저장 켜기

1. 위쪽 **File → Auto Save**를 누릅니다.
2. 같은 메뉴를 다시 열어 Auto Save 옆에 체크가 있는지 확인합니다.


자료를 받은 뒤 Python 예제의 인사말을 바꾸고 잠깐 기다립니다. 파일 탭의 저장되지 않은 변경 표시가 사라지는지 확인합니다. 그다음 ▶로 실행하면 새 문구가 출력됩니다.

자동 저장은 컴퓨터의 파일에 편집 내용을 저장합니다. 프로그램 실행은 ▶, GitHub 업로드는 브라우저의 Upload files로 진행합니다.

### 2. 글자가 작으면 화면 확대하기

**View → Appearance → Zoom In**을 눌러 메뉴와 코드, 교안을 읽기 편하게 확대합니다. 너무 커졌다면 같은 메뉴의 **Zoom Out**, 처음 크기로 돌아가려면 **Reset Zoom**을 선택합니다.

## 자료를 받은 뒤 확인하기

- [ ] Auto Save에 체크가 있습니다.
- [ ] 메뉴와 코드의 글자가 읽기 편합니다.
