# VS Code에서 GitHub 인증을 요청할 때

[← 설치와 첫 실행](README.md)

00의 자료 받기와 파일 업로드는 브라우저에서 GitHub에 로그인해 진행합니다. 이후 교과의 VS Code 기능이 GitHub 인증을 요청하면 아래를 참고합니다.

1. 요청 창에서 **Sign in with GitHub**를 선택합니다.
2. 열린 브라우저에서 수업용 사용자 이름과 요청한 권한을 확인합니다.
3. 인증을 진행하고 VS Code로 돌아갑니다.
4. 원래 진행하던 기능의 결과를 확인합니다.

[자료 받기와 업로드](04-git-github.md) · [Microsoft GitHub 인증 안내](https://code.visualstudio.com/docs/sourcecontrol/github#_authenticate-with-github)
